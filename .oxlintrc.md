# Lint rules

`.oxlintrc.json` keeps the React rules that catch real bugs — hooks order,
effect dependencies, refs / impure calls during render, components created
during render, missing keys — and turns two off on purpose:

- `react/set-state-in-effect`: every dialog resets its state in a
  `useEffect` on `open`. Radix keeps the dialog mounted while closed, so a
  key-based reset isn't available; the effect is the intended pattern here.
- `react/only-export-components`: modules deliberately co-locate a component
  with its small helpers (`askConfirm`, `useStore`, `captureTrim` …). The
  rule only affects fast-refresh granularity, not correctness.
